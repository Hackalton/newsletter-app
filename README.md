# the app

this is a newsletter application with three types of users

## Student user:

the student user can only read the newsletters. They can neither create nor update or delete one

## The journalist

the journalist can create newsletters, edit current news letters and delete them as well as read them

## The admin

the admin can edit student details, create student objects, delete them and view all of them
